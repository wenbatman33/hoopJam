# HOOP JAM · 2 on 2 街機籃球（直屏 3D）

NBA Jam 風格的 2v2 街機籃球：誇張灌籃、沒有犯規、可以推人、連進三球「著火」。
直式畫面，手機滿版、PC 置中顯示。球員是程式繪製的 Q 版大頭，灌籃與著火時有蓋板特寫動畫。

> **非官方同人作品**，與 NBA、各球隊及球員無任何關聯，未經其授權或背書。
> 遊戲中僅以文字使用隊名與球員姓名，不含官方隊徽；球員外觀為依膚色、髮型等特徵繪製的卡通造型。

## 陣容

30 支球隊、每隊 2 名代表球員，定義在 `src/config.js` 的 `TEAMS`。
陣容與背號是 2026-10-05 依 ESPN 各隊名單整理的 2026–27 球季版本；能力值（速度／投籃／灌籃／防守）與髮型鬍型為主觀設定，直接改該檔即可調整。

## 執行

免打包的 ESM 專案：`index.html` 用 import map 直接載入 `vendor/` 內的 three.js 與 lil-gui，不需要 npm、不需要 build。
因為用了 ES module，不能直接雙擊 `index.html`，要透過任一靜態伺服器開啟：

```bash
python3 serve.py        # http://localhost:5288（同網段手機可用電腦 IP 連入）
```

推到 `main` 後，`.github/workflows/deploy.yml` 會把 repo 內容原樣部署到 GitHub Pages。

## 操作

| 動作 | 鍵盤 | 觸控 |
| --- | --- | --- |
| 移動 | WASD / 方向鍵 | 左下搖桿 |
| 投籃（進攻）／跳（防守） | J 或 Z | 橘色大鍵 |
| 傳球（進攻）／抄截（防守） | K 或 X | 藍色鍵 |
| 渦輪（按住） | L / C / Shift | 綠色鍵 |
| 換人（防守時） | 空白鍵 / Q | 換人鍵 |
| 暫停 | Esc / P | ⏸ |

- **跳投**：按住投籃鍵起跳，在最高點放開 = PERFECT 加成；輕點一下則自動在最高點出手（無加成）。
- **灌籃**：按住渦輪衝向籃框，靠近時按投籃。
- **上籃**：籃下不開渦輪直接按投籃。
- **推人**：防守時 渦輪 + 抄截鍵（消耗渦輪），持球者被推倒會掉球。
- **蓋火鍋**：對手出手瞬間在他面前起跳；對手灌籃時在籃下起跳也有機會蓋掉。
- **著火**：同一球員連進 3 球且期間對手沒得分 → 渦輪無限、命中率大增，直到對手得分。
- 進攻時操控權自動跟著持球者；防守時用換人鍵切換。

## DEV 微調工具

按 `` ` `` 或 `F2`、或點右下角 ⚙ 開啟。

- 鏡頭、HUD、觸控按鍵、手感參數、對手 AI 難度、視覺皆可即時調整
- HUD 與按鍵可直接拖曳；PC / Mobile 版面分開編輯
- 「狀態觸發」可立刻進入著火、灌籃、節末、終場等畫面
- 「💾 匯出」會把所有數值複製成 JSON，貼回給 Claude 即可寫進 `src/config.js`
- 調整值暫存在 localStorage（`hoopjam_dev_overrides_v1`），「重置為預設」可清除

## 結構

| 檔案 | 內容 |
| --- | --- |
| `src/config.js` | 所有可調參數：手感、視覺、AI 難度、隊伍、PC / Mobile 版面 |
| `src/game.js` | 渲染、鏡頭、狀態流程（選單示範賽 → 比賽 → 節間 → 終場） |
| `src/match.js` | 比賽規則：計分、著火、進攻時間、蓋火鍋、抄截 |
| `src/player.js` | 球員狀態機與動畫選擇 |
| `src/ball.js` | 球：持球 / 投籃 / 傳球 / 自由球物理 |
| `src/ai.js` | AI：持球進攻、無球跑位、盯人防守、搶球 |
| `src/models.js` `src/poses.js` | GLB 角色載入、球衣重新上色、骨骼瞄準手臂動作 |
| `src/court.js` `src/textures.js` `src/effects.js` | 球場、程序化貼圖、粒子 |
| `src/ui.js` `src/input.js` `src/audio.js` `src/devtools.js` | 介面、輸入、合成音效、DEV 工具 |

角色模型來源見 `assets/models/CREDITS.md`；第三方函式庫版本見 `vendor/README.md`。
